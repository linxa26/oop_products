
# Учебный проект oop_products

Учебный проект на Python для закрепления основ объектно-ориентированного программирования (ООП).

В проекте реализованы классы `Product` и `Category`, позволяющие создавать товары, объединять их в категории и подсчитывать количество категорий и товаров.


## Реализованные классы

### Класс Product

Класс `Product` предназначен для представления отдельного товара.

Атрибуты:

- `name` (`str`) — название товара.
- `description` (`str`) — описание товара.
- `price` (`float`) — цена товара.
- `quantity` (`int`) — количество товара на складе.

Атрибуты создаются при инициализации объекта через метод `__init__`.

### Класс Category

Класс `Category` предназначен для объединения товаров в категории.

Атрибуты экземпляра:

- `name` (`str`) — название категории.
- `description` (`str`) — описание категории.
- `products` (`list[Product]`) — список объектов класса `Product`.

Атрибуты класса:

- `category_count` — количество созданных категорий.
- `product_count` — общее количество товаров, переданных при создании категорий.

Счётчики автоматически увеличиваются при создании нового объекта `Category`.

## Пример использования

```python
from src.product import Product, Category

phone = Product("Samsung", "Смартфон", 50000.0, 10)
iphone = Product("iPhone", "Смартфон", 80000.0, 5)

category = Category(
    "Смартфоны",
    "Мобильные телефоны",
    [phone, iphone],
)

print(category.name)
print(len(category.products))
print(category.products[0].price)
print(Category.category_count)
print(Category.product_count)
```

Результат выполнения в новом процессе:

```text
Смартфоны
2
50000.0
1
2
```

Список `products` хранит ссылки на объекты класса `Product`.

Счётчик `product_count` обновляется при создании категории. Если позднее добавить товар в список через `append()`, счётчик автоматически не изменится.

## Установка проекта

Для управления зависимостями используется Poetry.

Требуется Python 3.13 или совместимая версия, разрешённая настройками `pyproject.toml`.

Клонируйте репозиторий и перейдите в папку проекта.

Установите зависимости:

```bash
poetry install
```

## Тестирование

В проекте используется `pytest`.

Файл `tests/test_product.py` содержит четыре теста:

1. `test_product_init` — проверка атрибутов товара.
2. `test_category_init` — проверка инициализации категории.
3. `test_category_count` — проверка счётчика категорий.
4. `test_product_count` — проверка счётчика товаров.

### Запуск тестов

```bash
poetry run python -m pytest tests/test_product.py -v
```

Результат последнего запуска:

```text
4 passed
```

### Проверка покрытия

Для оценки покрытия используется `pytest-cov`.

```bash
poetry run python -m pytest tests/test_product.py --cov=src.product --cov-report=term-missing
```

Результат:

```text
Name             Stmts   Miss  Cover
------------------------------------
src/product.py      15      0   100%
------------------------------------
TOTAL               15      0   100%
```

Покрытие функционального кода модуля `src/product.py` составляет 100%.

### Проверка стиля кода

Для проверки качества оформления используется `flake8`.

```bash
poetry run python -m flake8 src/product.py tests/test_product.py
```

При отсутствии замечаний команда завершается без вывода ошибок.
